# AnimeWall mascots

Place the theme mascot images in this folder using these filenames:

- `ph.png` - blue-haired AnimeWorld-inspired mascot for the default PH theme
- `rias-red.png` - Rias Gremory mascot for the red theme
- `silence-suzuka.png` - Silence Suzuka mascot for the green theme
- `rias-pink.png` - Rias Gremory mascot for the pink theme

Use transparent PNG images with these exact filenames. The mascot is hidden automatically until its image file exists.
